# vital-stock-releases
Vital Stock es un sistema de gestión para ferreterías y comercios minoristas, diseñado para controlar inventario, ventas, compras, clientes, proveedores, caja, presupuestos, remitos, devoluciones y reportes de forma centralizada.
Incluye funcionalidades para:

gestión de productos y stock;
movimientos de compras y ventas;
control de clientes y proveedores;
administración de usuarios y permisos;
caja diaria y cierre de movimientos;
emisión y exportación de reportes PDF/Excel;
generación de documentos comerciales y control financiero.
Este proyecto está pensado para uso local o en entornos empresariales pequeños y medianos, con una interfaz desktop desarrollada en JavaFX y base de datos SQLite.

Incluye el instalador ejecutable (.exe) para facilitar la puesta en marcha del sistema en Windows.

Versión con enfoque más profesional
Vital Stock es una solución de gestión integral para ferreterías y negocios de comercio minorista, orientada a optimizar el control operativo, financiero y comercial del negocio. Su propósito es centralizar el manejo de inventario, compras, ventas, clientes, proveedores, movimientos de caja y reportes administrativos en una sola herramienta.

Desarrollado en Java con JavaFX y SQLite, el sistema ofrece una experiencia desktop rápida y funcional, ideal para pequeñas y medianas empresas que buscan automatizar procesos sin depender de complejas soluciones empresariales.
